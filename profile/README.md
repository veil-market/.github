# Veil Marketplace

Every Meme Has a Veil. Veil is a lavender hooded character who takes on the look of
whichever meme it meets. The Veils are 3D characters minted as NFTs on Solana.

- Website: https://veil-marketplace.vercel.app
- X: [@VeilMarketX](https://x.com/VeilMarketX)
- Buy and sell on [Magic Eden](https://magiceden.io): each Veil's page on the website links to it.

## Staying safe

- The website never asks your wallet to sign. Connecting shares your public address and nothing else.
- We never send the first DM, and we never ask for a seed phrase or private key.

## Independence

Veil Marketplace is an independent project. It isn't affiliated with the VEIL protocol, Magic Eden,
or any meme project or brand shown in fan-inspired artwork. The Fan Art Veils are unofficial.
